About Me & What Drives My Work

Ansh Kumar
AI Agent & Automation Builder

I'm Ansh, a student who got into AI agents and automation almost by accident — I was trying to automate a repetitive task for myself, ended up in an n8n workflow at 2 AM, and haven't stopped since.

Since then I've built several personal projects covering lead qualification agents, voice AI flows with Vapi, and logic-driven automations using the OpenAI and Claude APIs — mostly to understand how these systems actually behave under real inputs, not just in a demo. I care more about a workflow that doesn't break on edge cases than one that just looks good in a screenshot.

I'm still early in this — most of what's below is practice work, not client work — but I'm actively looking to take on my first real builds and learn by shipping something that has to work for someone other than me.

Engineering Approach

How I Build Systems

My 4-step framework for turning complex requirements into resilient automated workflows.

01

Understand the Problem

Map out the exact manual bottleneck, data inputs, API endpoints, and desired end outcomes before writing any code or prompts.

02

Design the Agent

Draft strict LLM system prompts, define JSON schema structures, set up error fallbacks, and design the n8n logic flowchart.

03

Build & Test

Connect webhooks and APIs, test edge-case payloads, verify voice latency, and ensure strict input/output validation.

04

Ship & Monitor

Deploy to production, configure execution logging, set up error alerts, and refine agent performance over time.
